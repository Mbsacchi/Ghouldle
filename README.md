# GHOULDLE — 東京喰種

Jogo web interativo (diário e infinito) de adivinhação do universo de **Tokyo Ghoul** e **Tokyo Ghoul:re**.

## Modos de Jogo
- **壱 Clássico:** Comparação de atributos (Gênero, Espécie, Afiliação, Células RC, Classificação e Arco de Estreia) com virada 3D sequencial e anexos confidenciais progressivos.
- **弐 Citação:** Descubra o autor de falas marcantes da obra com liberação gradual de arco, contexto e facção.
- **参 Máscara & Olho:** Identifique o personagem pelo recorte aproximado de sua máscara ou *Kakugan*, com zoom regressivo a cada tentativa.

## Como Rodar Localmente

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```
